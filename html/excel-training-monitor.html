Excel Training Monitor

Excel Training Monitor uses excel sheets to create a custom alert that can display in a grid, pie chart and a list like notifictaion that can be set to trigger a reminder at any time of your choosing.

Installation

  1. Download ExcelTraingMonitor.Zip from here: GITHUB.
  2. Unpack ExcelTraingMonitor.Zip using decompression software.
  3. Open unzipped ExcelTraingMonitor folder.
  4. Double-Click the build.bat file.
  5. When it's finished building you will find an executable in the publish folder.
  6. Double-Click this exe to start the program
