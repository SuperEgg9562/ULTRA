Excel Training Monitor

Excel Training Monitor is a Matrix-themed training spreadsheet monitor and GridBook editor. It can create and edit Excel files, watch training status changes, show grouped reminders, export CSV and chart images, print reports to PDF, and send optional ntfy.sh reminders to phones or email.

Installation

  1. Open the latest GitHub Release.
  2. Download the portable release ZIP, or download the installer if one is attached.
  3. For the portable ZIP, extract it and run ExcelTrainingMonitor.exe.
  4. For the installer, run ExcelTrainingMonitorSetup-<version>.exe and follow the prompts.

Build From Source

  1. Install the .NET 8 SDK or newer from Microsoft.
  2. Clone the source repository.
  3. Run build.bat from the repository root.
  4. The script checks dependencies, increments the patch version, builds a self-contained release, and creates ZIP assets under artifacts.
  5. Install Inno Setup only if you also want an installer EXE.
